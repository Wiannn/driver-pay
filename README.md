# 司机工资结算系统

一款零依赖、单文件的司机工资结算工具。双击即可打开，数据存在浏览器本地（localStorage），支持云端扩展。

## ✨ 已实现功能

### 司机管理
- 司机信息增删改查（姓名、车牌、手机号必填 11 位校验）
- 手机号输入错误即时提示

### 路线与公里
- **目的地按区域分组**：外一外二系 / 外四外五系 / 洋山系
- **基础公里表自动查表**：始发地 → 各目的地的单段公里数可在管理弹窗里编辑
- **同区域去重**：连续步骤同区域不加第二段公里（进外一 → 提东森只算外一的公里）
- **自动算总公里**：搭完始发地+步骤，公里自动累加
- **路线库模板**：常用路线存成模板，趟次录入直接选
- **直接搭建**：临时路线不用存路线库，趟次录入时直接搭

### 提成自动规则
| 步骤组合 | 自动提成 |
|---------|---------|
| 纯进 1 段（外系） | 10 |
| 纯进 1 段（洋山系） | 0 |
| 纯提 1 段（洋山系） | 100 |
| 纯提 1 段（外系） | 10 |
| 进+提（同区域） | 30 |

公里和提成都可手动覆盖自动值。

### 趟次录入
- 月份筛选 + 司机筛选
- 两种模式：选模板 / 直接搭建（随时切）
- **箱号列**：双击编辑，仅允许字母数字，自动转大写
- **备注列**：双击编辑，支持任意文字
- 所有数据冗余存路线快照（route_origin + route_steps + route_name），历史不受模板变更影响

### 出勤登记
- 月历视图，点击格子循环切换状态：正常 → 休息 → 台风 → 清空
- 颜色区分状态：🟦 正常 / 🟧 休息 / 🟥 台风
- 鼠标悬停显示日期、状态、当日趟次数
- 顶部统计：正常 X 天 / 休息 X 天 / 台风 X 天 / 趟次记录 X 天（对照）

### 加油录入
- 按月份 + 司机筛选
- 加油日期、加油量（升）、单价、总金额、备注

### 结算与导出
- 按月份生成每位司机的工资结算卡
- 自动算：上班天数（优先取出勤登记）、总公里、总提成、总加油、实发工资
- 一键导出 Excel（CSV）

### 备份恢复
- 导出 JSON 备份文件（包含全部数据）
- 从 JSON 恢复
- 建议定期导出一份备份

## 🚀 使用方式

### 本地使用（最简单）
直接双击 `司机工资结算.html`，任何现代浏览器都行。

### GitHub Pages 在线使用
打开：`https://wiannn.github.io/driver-pay/司机工资结算.html`

**注意**：每个人打开自己的浏览器用自己的数据，因为 localStorage 只存在本地。多人共享数据需要上云（见下方）。

## 🔧 管理目的地/始发地/基础公里

页面「线路价目」页 → 顶部按钮：
- **管理始发地**：增删行驶起点
- **管理进目的地**：增删进段目的地，按区域分组显示，可拖拽分组
- **管理提空箱目的地**：同上

**拖拽分组**：把目的地标签拖到「外一外二系」「外四外五系」「洋山系」三个区域卡片里即可。

**基础公里表**在代码 `defaultDb()` 里的 `base_km` 对象，可在「管理始发地/目的地」时动态补齐，后续计划提供专门的基础公里表编辑弹窗。

## ☁️ 上云（多人共享数据）

当前版本数据只存在浏览器本地。要多人共享同一份数据：

1. 注册 https://supabase.com
2. 创建项目（Region 选 Singapore，国内延迟低）
3. SQL Editor → 粘贴 `supabase_setup.sql` → Run
4. Settings → API → 复制 Project URL 和 anon public key
5. 打开 `司机工资结算.html`，替换第 1188-1189 行：
   ```javascript
   var SUPABASE_URL = 'https://你的项目.supabase.co';
   var SUPABASE_ANON_KEY = '你的anon key';
   ```

之后每个人打开同一个 URL 的网页，数据实时同步。
